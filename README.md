# 数学一 + 408 个人学习工具

本项目服务于日常学习：直接阅读原始 PDF 或页面图片，向 Claudian 询问当前问题，再按需保存自己的理解、错题和周复盘。项目不再以“把全部教材准确转换为 Markdown”为目标。

在 Obsidian 中打开 `D:\Postgraduate-Study\vault`，从 `学习主页.md` 开始。首页只有五个学习入口：数学一、408、错题本、周复盘、原始资料。使用说明见 `vault/日常辅导.md`，控制为一页。

原始 PDF 位于 `sources-original/`，永久只读；`import-inbox/` 原文件继续保留。`vault/教材页面图片/` 提供已有完整页面图片与 PDF 物理页码的中文索引。若原件位于 Vault 外且链接不能打开，复制页面显示的绝对路径到文件管理器或 PDF 阅读器，并按标注页码定位。

`vault/90-Parsed-Sources/` 中的完整页面图片和必要映射继续保留。已确认无人修改的失真机器正文、重复报告和可重建索引已移到本地可恢复的清理暂存区，不再进入日常检索。遇到公式乱码、题干缺失或版面错序时，以原始 PDF/页面图片为准；可以把单页截图附给支持图像的模型，不自动重跑整本 OCR。

日常只使用两个模板：

- `vault/99-笔记模板/知识笔记模板.md`
- `vault/99-笔记模板/错题模板.md`

只有用户明确要求保存时才写入笔记。Claudian 当前使用 read-only 时，会在聊天中输出可复制 Markdown。一般讲解不依赖 accepted 页面；“严格资料查询”仍保留 accepted-only 门禁。

旧导入、解析、检索和审核代码保留在 `scripts/`，技术说明集中在 `vault/00-系统维护/`。它们不再是日常学习前置步骤，也不会被自动继续扩建。

安全边界见 `AGENTS.md`：原件、图片、真实 manifest、基线、模型和本地运行数据不进入 Git；不自动安装、下载、批量解析或调用外部 API。
