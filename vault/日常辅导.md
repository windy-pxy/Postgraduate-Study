# 一页使用说明

## 第一次学习只做三步

1. 从 [[教材资料|原始资料]] 打开 PDF 或对应页图片；也可以把当前题目截图附到 Claudian。
2. 直接说明你不懂的地方和你的尝试。一般讲解不需要 accepted 页面；资料文字和公式冲突时，以原页为准。
3. 值得复习时再说“保存笔记”或“加入错题本”。当前只读模式会输出可复制 Markdown，分别放入 `03-知识笔记/` 或 `04-错题本/`。

回看错题：打开 [[04-错题本/错题本导航|错题本]]，选择已有笔记，再让 Claudian 根据“下次提醒”出一道相似题。

## 三条可直接复制的指令

```text
请解释这个知识点，并针对我不理解的地方举一个简单例子。若使用一般知识，请标注“模型补充”。
```

```text
请分析我附上的题目和作答：先核对题干与公式，再指出错在哪里、正确思路和下次提醒。看不清的符号不要猜。
```

```text
请把刚才内容整理成知识笔记（或加入错题本）。缺失信息留空；有资料时写真实资料名称和 PDF 页码。
```

若 Obsidian 不能打开 Vault 外的 PDF，按 [[教材资料|原始资料]] 中显示的绝对路径在文件管理器打开，再跳到标注的 PDF 物理页码。复杂题目允许直接保留截图。
