# 待审核列表

当前未添加任何审核条目。此页是人工维护的系统清单，不代表学习记录或学科内容。

待确认的知识关系、来源页码、重名目标和无法核实的信息先写普通文本。每项记录：日期、涉及笔记路径、疑问、已有证据、待确认事项、处理状态。没有证据时明确写“待核实”，不要创建猜测双链。

项目根目录的 `review-queue/import-plans/` 保存 Phase 2A 显式 `plan --save` 生成的单文件导入计划；本页继续记录语义关系和来源疑问。计划分类不完整时不能 apply。完成审核不自动删除原记录或计划；导入流程见 [[00-System/Source-Import-Guide|安全导入指南]]。
